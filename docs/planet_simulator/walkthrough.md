# 太陽系学習シミュレーター 構築完了

React Three Fiber と Tailwind CSS を用いて、ブラウザ上で直感的に太陽系の動きや特徴を学べるシミュレーターを構築しました。

## 実装内容

- **3D宇宙空間の構築**: `@react-three/fiber`と`@react-three/drei`を使用し、星空の背景、太陽の光源、カメラコントロール（`OrbitControls`）を実装しました。環境光およびポイントライトを調整し、天体の明るさと影のコントラストを美しく表現しています。
- **惑星データの定義**: 各惑星の大きさ、太陽からの距離、公転速度、自転速度、そして学習用の情報を網羅したデータを構築しました。
- **軌道とアニメーション**: `useFrame`を用いて各惑星がそれぞれ異なる速度で公転および自転するアニメーションを実装。さらに、薄い白い線で各惑星の軌道を描画し、位置関係を視覚的に捉えやすくしています。
- **インタラクティブUI**: 惑星をクリックすると、その惑星の詳細情報（特長、サイズなどの事実データ）が、宇宙を意識した美しいすりガラス調のカードで手前に表示されます。
- **レスポンシブなダークテーマ**: Tailwind CSS の v4 を使用し、深い青と黒を基調とした洗練されたデザインに仕上げています。

## 確認方法

以下のコマンドで開発サーバーを起動し、ブラウザ機能を確認してください。

```bash
cd app
npm run dev
```

### マウス操作

- **カメラの回転**: マウスの左ボタンドラッグ
- **カメラのズーム**: マウスホイール（スクロール）
- **詳細の表示**: 任意の惑星をクリック

## トラブルシューティング（バグ修正）

当初、最新の `Vite (React 19)` と `@react-three/fiber@9.5.0` の組み合わせにより、Three.js の初期化時に `createReconciler` 内で React のランタイム例外が発生し、画面が真っ暗になる不具合が発生しました。
この互換性問題を解決するため、安定版の `React 18` と `@react-three/fiber@8` へダウングレードする修正を行い、正常に動作するようになっています。
