# 太陽系学習シミュレーター 実装計画

## 概要
惑星の動きや特徴をビジュアル的に学べるシミュレーターアプリを構築する。
ユーザーは3D空間上で太陽系の惑星の公転・自転を観察でき、各惑星をクリックすることで詳細情報（サイズ、太陽からの距離、公転周期、主な特徴）を学習できる。

## 技術スタック
- **フロントエンドフレームワーク**: React (Vite + TypeScript)
- **3Dグラフィックス**: Three.js, @react-three/fiber, @react-three/drei
- **スタイリング**: Tailwind CSS

## 実装ステップ

### 1. プロジェクトの初期化
- Viteを使用してReact + TypeScriptのプロジェクトを作成する。
- Tailwind CSS、Three.js、@react-three/fiberなどの必要なライブラリをインストールする。

### 2. コンポーネント設計
- `Scene`: 3D空間全体を管理するコンポーネント。カメラ制御 (`OrbitControls`) を配置。
- `Sun`: 太陽を描画し、光源を配置するコンポーネント。
- `Planet`: 各惑星を描画し、公転・自転のアニメーションを処理するコンポーネント。クリックイベントで情報を親に伝達する。
- `PlanetInfo`: 選択された惑星の詳細情報を画面上にオーバーレイ表示するUIコンポーネント。

### 3. データ構造定義
各惑星の以下のデータを保持する設定データ (`planets.ts`) を作成する。
- 名前（日本語/英語）
- 色、テクスチャURL（必要に応じて）
- サイズ（半径）
- 太陽からの距離
- 公転速度
- 自転速度
- 特徴の説明テキスト

### 4. 3D描画とアニメーション実装
- `useFrame` を使用して、各惑星のオブジェクトを公転軌道に沿って回転させ、同時に自転させる機能を実装する。
- 宇宙空間の背景（星空）を設定する（`Stars` コンポーネント等を利用）。

### 5. UIとインタラクション実装
- 惑星をクリック可能にし、クリック時にUIオーバーレイ (`PlanetInfo`) を表示する。
- ズームイン/アウト、視点移動ができるようにする。

### 6. スタイリングと調整
- 洗練されたダークモード寄りの宇宙らしいUIデザインを適用する。
- レスポンシブ対応を行う。

## 自動テスト・確認方針
- 開発サーバー (`npm run dev`) を立ち上げ、ブラウザから動作確認を行う。
- アニメーションが滑らかに動作するか、各惑星の情報が正しく表示されるかを目視で確認する。
